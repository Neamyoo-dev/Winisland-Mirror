## 下载

下载在[Github Release](https://github.com/Neamyoo-dev/Winisland-Mirror/releases/)

## 构建项目

安装包含 **Cargo** 的 **Rust** 工具链，然后运行：

```cmd
git clone https://github.com/Neamyoo-dev/Winisland-Mirror.git

cd Winisland-Mirror

cargo build --release
```
